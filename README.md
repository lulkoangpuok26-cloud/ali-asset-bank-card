# Ali Asset Global Pay

A responsive, premium dark-mode bank card dashboard inspired by the supplied Ali Asset Global Pay reference image.

## Included

- Responsive mobile-first dashboard layout
- Gold-and-black virtual card with masked number, expiry, and cardholder
- Balance visibility toggle
- Top Up, Transfer, QR scanner, payment-method, and Pay with App interactions
- Bottom navigation with active state
- No build step or dependencies required

## Run locally

Open `index.html` in a browser, or serve the directory with any static web server.
